## 🚀 Featured Projects

### 📱 [WatchTracker](https://github.com/igor-cotrim/WatchTracker)
A SwiftUI app for tracking movies and TV shows, with a Node.js + Supabase backend.
- **SwiftUI** with MVVM + Clean Architecture
- TMDB API integration with custom backend layer
- Runtime language switching, multi-platform support
- [WatchTracker Backend](https://github.com/igor-cotrim/watch-tracker-backend)

### 📊 [Notion Graphs](https://github.com/igor-cotrim/notion_graphs)
A workaround for Notion's limitation of allowing only one native chart per page — embed as many custom charts as you want via parameterized URLs.
- **Node.js + Express** proxy server that queries the **Notion API** server-side (bypassing CORS)
- Embeddable **HTML + Chart.js** page that reads URL query params (`groupBy`, `filter`, `title`) to render distinct charts
- Dark-themed configurator UI to build embed URLs visually with live preview
- Deployed on Render, embedded in Notion via `/embed` blocks

### 🧠 [Memô](https://github.com/igor-cotrim/memo)
A modern flashcard app powered by the **FSRS** spaced-repetition algorithm.
- Monorepo with **pnpm workspaces** and end-to-end **TypeScript** type safety
- **Node.js + Express** backend with **Drizzle ORM** and **PostgreSQL** (Supabase)
- **React** + **Vite** + **Tailwind CSS v4** on the frontend
- Supabase Auth with session management, CSV import/export, dark mode, i18n (EN/PT-BR)

### 🎓 [Reserve+](https://github.com/igor-cotrim/reserveplus)
Reservation system for academic environments — my final undergraduate project.
- Jamstack with **Next.js 13** and **Strapi**
- Dockerized environments for dev and production
- Fully responsive, reusable components with **TailwindCSS**

### ⚛️ [Clean React](https://github.com/igor-cotrim/clean-react)
Clean Architecture applied to a React project.
- TDD, SOLID principles, and Design Patterns
- Unit and end-to-end tests

### 🎮 [Won Games](https://github.com/igor-cotrim/wongames-client)
